## Deskripsi

Sistem Absensi Guru merupakan aplikasi berbasis ASP.NET Core MVC yang digunakan untuk membantu proses pengelolaan data guru dan absensi secara terkomputerisasi. Sistem ini memudahkan administrator dalam mengelola data guru, jabatan, absensi, izin, serta menghasilkan laporan absensi.

---

## Tujuan

Aplikasi ini dibuat sebagai salah satu tugas mata kuliah Sistem Informasi dengan tujuan menerapkan konsep analisis, perancangan, implementasi, dan pengelolaan basis data menggunakan ASP.NET Core MVC.

## Cara Menjalankan Project

1. Clone repository ini.
2. Import database **db_absensi_guru** ke MySQL/MariaDB.
3. Sesuaikan connection string pada file `appsettings.json` atau `ApplicationDbContext`.
4. Jalankan aplikasi menggunakan ASP.NET Core.
5. Buka browser dan akses aplikasi.
